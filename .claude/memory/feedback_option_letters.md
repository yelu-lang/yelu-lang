---
name: Use Latin letters for option/choice lists
description: When presenting numbered/lettered options for the user to pick, use 1/2/3/4 or a/b/c/d, not Greek letters
type: feedback
---

When listing options for the user to choose from, use Latin letters (a, b, c, d)
or digits (1, 2, 3, 4). Do not use Greek (α, β, γ, δ).

**Why:** User explicitly preferred Latin in chat. Greek requires more cognitive
overhead to map back to the option, and is harder to type in replies.

**How to apply:** Any "pick one of" prompt — e.g. "next-step options" lists,
multiple choice, alternative approaches. Stick to a/b/c/d or 1/2/3/4.
