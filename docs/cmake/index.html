yelu-cmake

Comparing the yelu DSL against raw cmake for the same build logic

What is yelu-cmake?

yelu-cmake is the cmake target pack for yelu. It provides a typed surface language that compiles to standard cmake. The compiler performs type erasure: yelu's typed AST is lowered to cmake's stringly-typed AST, then pretty-printed as CMakeLists.txt. The output is verified for structural equivalence against reference cmake implementations.

Checking pipeline

Stage What it catches cmake equivalent Status
typecheck bool where string expected, path vs string, cache type mismatch Silent empty string / configure-time error far from source 14 theories
wellform Undeclared cvar/target, typo'd variable names, cross-theory refs No checking — empty string propagation done
effect target_* only in configure mode, genex restrictions Runtime cmake error next
lower Structural validity during AST → cmake emission N/A partial
configure REQUIRED find_package, math(EXPR), policies cmake itself 61 RunCMake compat
